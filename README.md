## 📘 Project Description

This dashboard visualizes sales data from 2023 to uncover trends, performance insights, and opportunities for optimization in 2024. It includes:

- ✅ **Monthly Sales Trend**
- 🥧 **Sales Breakdown by Product Category (Pie Chart)**
- 🗺️ **Geographical Sales (Map by State)**
- 🧱 **Treemap of Product Categories**
- 📈 **KPIs for Total Revenue, Quantity, and Averages**

Built using:
- 🧠 **Tableau Public 2025.1**
- 📁 Cleaned `.csv` data preprocessed with Python & Pandas
- 🎯 Optimized for visual storytelling and executive overview

---

## 📦 Data Used

- `original.xlsx` (raw)
- `cleaned_sales_data_2023.csv` (processed)
- Includes fields:
  - `Product Category`, `State`, `Total Cost (USD)`, `Date`, `Quantity`, etc.

---

## 📌 Features

- 📊 Interactive charts with tooltips and filters
- 🧭 User-friendly layout with visual hierarchy
- ⚙️ Dashboard actions: click a category or state to filter all visuals

---

## 🧠 How It Was Built

1. Cleaned and enriched raw data in Python
2. Exported to `.csv` and imported in Tableau
3. Created 4 core visualizations:
   - Line chart, pie chart, map, treemap
4. Combined into a **single dashboard**
5. Published on Tableau Public with live share link
